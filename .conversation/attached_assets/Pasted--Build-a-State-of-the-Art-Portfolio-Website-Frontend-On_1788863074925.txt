I will provide **two portfolio screenshots/images** as visual references.

The two screenshots represent **two different visual themes/designs**. I want you to build a single portfolio website that contains **both themes**, with a smooth theme switcher.

## IMPORTANT — SCOPE

For this phase, build **ONLY the frontend UI/design**.

### Do NOT build:

* Backend
* Database
* Authentication
* APIs
* CMS
* Admin dashboard
* Contact-form backend
* Email integrations
* External data fetching
* Deployment configuration
* Unnecessary functionality

Use **dummy/static data** everywhere for now.

The goal of this phase is to get the **design, layout, animations, responsiveness, typography, spacing, components, and theme system** right while keeping token usage reasonable.

I will attach **two screenshots**.

Study both screenshots carefully before implementing anything.

The screenshots are the primary design references.

Do NOT simply copy them as images or create a rough approximation.

Instead:

* Recreate the visual language of each design.
* Preserve the important layout decisions.
* Preserve the overall composition.
* Preserve typography hierarchy.
* Preserve spacing and proportions.
* Preserve cards, sections, navigation, buttons, decorative elements, etc.

**Do not merge their visual styles into one generic design.**

# 3. Theme Switcher

Add a clearly accessible **theme switch button**.

For example:

`Theme 1 ↔ Theme 2`

The exact UI can be designed to fit the portfolio.

When the user switches themes:

* Transition must be extremely smooth.
* It should feel intentional and premium.
* Avoid a basic instant CSS swap.
* Use tasteful animations/transitions.
* Keep the transition fast.
* Avoid excessive animation that makes the website feel slow.
* Preserve the user's current scroll position.
* Do not reload the page.
* Do not navigate to another page.

The switch should feel like switching between **two professionally designed portfolio experiences**, not simply changing colors.

---

# 4. IMPORTANT: SAME CONTENT POSITIONING / FORMATTING

Even though the two themes look different, the **information hierarchy and formatting should remain consistent**.

For example:

If Theme 1 places:

`Name → left side`

then Theme 2 should also treat the name as the corresponding primary hero element rather than randomly moving the information elsewhere.

If:

`Profile information → left`
`Visual/project element → right`

in the main composition, maintain the same underlying content hierarchy in Theme 2.

The two themes should feel like:

> **Same portfolio + two completely different art directions**

rather than two unrelated websites.

This is important.

The result should look like it was designed by a **strong senior product designer / creative developer**.

Aim for:

* Strong visual hierarchy
* Intentional typography
* Excellent spacing
* Precise alignment
* Good contrast
* Strong composition
* Sophisticated interaction design
* Subtle motion
* Responsive behavior
* Consistent design system
* Professional portfolio-level polish

Think **state-of-the-art personal portfolio**, not a template.
